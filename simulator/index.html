Monte Carlo: what does a week really look like?

One simulated week is one possible outcome. Here the same network (from the Live tab) is replayed hundreds of times with different random customers. The spread shows the risk; the confidence interval shows how sure we are of the average. If the interval won't tighten, an input needs better data.

Distribution of weekly profit

Each bar counts simulated weeks. Dashed line = break-even.

Convergence of the estimate

Running mean of weekly profit with its 95% confidence band. A narrowing band means more runs add little; the remaining uncertainty is in the inputs (see Sensitivity).

Reality check against real operators

Layout A/B: is a new station worth it?

Both layouts face exactly the same customers in each replication (common random numbers), so the difference is due to the layout, not luck. This answers investor questions like "what is one more station worth per week?"

Sensitivity: which unknowns move profit the most?

Each input is pushed to the low and high end of its plausible range while everything else stays put. Long bars are the inputs that most change the answer, so they are what to measure first (street survey, pilot data). Bar labels show each input's data confidence.

Blue = weekly profit with the input at its low value; orange = at its high value. Vertical line = base case.

Data & sources: how real is each number?

Every input the simulation uses, where it came from, and how much to trust it. Investors should be able to check any number. Low-confidence inputs are exactly what the pilot and the daily research routine are working to replace.
