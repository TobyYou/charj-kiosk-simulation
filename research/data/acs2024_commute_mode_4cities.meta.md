# acs2024_commute_mode_4cities.csv
- **Source:** US Census Bureau ACS 2024 1-year, table B08301 (Means of transportation to work), served unchanged via Census Reporter's open API (api.census.gov now requires a key).
- **URL:** https://api.censusreporter.org/1.0/data/show/latest?table_ids=B08301&geo_ids=16000US3651000,16000US4752006,16000US1714000,16000US1245000
- **Downloaded:** 2026-11-08 (release id acs2024_1yr). Re-checked by the orchestrator, not only the research agent.
- **Scope:** working residents aged 16+, city-wide (Nashville = Metro balance). Not students; campus areas walk far more. Use for between-city scaling only.
